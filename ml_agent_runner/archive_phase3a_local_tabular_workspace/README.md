# Archived Phase 3A Local Tabular Workspace

This directory preserves the working Phase 3A application before Phase 3B
added conversational standardized dataset setup. It retains the general chat,
OpenAI-native file attachments, and per-chat local pandas workspace exactly as
they existed at the phase boundary.

It contains source and dependency files only. API keys, uploads, temporary
files, and Python cache directories are intentionally excluded.
